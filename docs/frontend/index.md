# Frontend FinBoost+

## Visão Geral

O frontend do **FinBoost+** é uma aplicação web desenvolvida em React, com interface intuitiva e responsiva para controle financeiro compartilhado. Permite que usuários gerenciem finanças pessoais e em grupo de forma colaborativa e eficiente.

## Principais Funcionalidades

- Gestão de grupos: criação e gerenciamento de grupos de despesas
- Controle de despesas: adição, edição e categorização de transações
- Visualização de dados: gráficos interativos de saldos e gastos
- Autenticação: login, registro e perfil de usuário
- Temas: suporte a modo claro e escuro
- Responsividade: interface adaptada para desktop, tablet e mobile
