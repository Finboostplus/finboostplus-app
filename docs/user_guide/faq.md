# FAQ - Perguntas Frequentes

Respostas às dúvidas mais comuns sobre o uso do FinBoost+.

## Conta e Acesso

### Como criar uma conta no FinBoost+?
Acesse a página inicial e clique em "Criar Conta". Preencha seus dados pessoais, crie uma senha segura e confirme sua conta através do email enviado.

### Posso usar o FinBoost+ sem internet?
Sim, parcialmente. Quando instalado como PWA, você pode visualizar dados já sincronizados e registrar novas transações offline. Tudo será sincronizado quando a conexão for restabelecida.

## Transações e Finanças

### Como categorizo minhas transações?
Ao adicionar uma receita ou despesa, selecione a categoria mais adequada.

### O FinBoost+ se conecta com meu banco?
Atualmente não. O registro de transações é manual, garantindo total controle e privacidade sobre seus dados financeiros.

## Grupos e Despesas Compartilhadas

### Como funciona a divisão de despesas?
Quando você adiciona uma despesa a um grupo, pode escolher como serão divididos os gastos (igual ou personalizada).

### Posso alterar como uma despesa foi dividida?
Atualmente não, esta funcionalidade será adicionada em breve.

### O que acontece se eu remover alguém do grupo?
Antes de remover um membro:
1. Certifique-se de que não há pendências financeiras
2. Liquide todas as contas em aberto
Após a remoção, o membro perderá acesso ao grupo.

### Como liquidar contas entre membros do grupo?
1. Acesse "Saldos" dentro do grupo
2. Veja quem deve para quem
3. Registre pagamentos feitos
4. Marque como "pago" após confirmação

## Segurança e Privacidade

### Meus dados estão seguros?
Sim. Utilizamos:
- Autenticação JWT com tokens seguros

### Posso ativar autenticação de dois fatores (2FA)?
Ainda não, esta funcionalidade será adicionada em breve.

## Funcionalidades Técnicas

### Como instalar o FinBoost+ como aplicativo?
**Desktop:** Acesse pelo navegador e clique no ícone de instalação na barra de endereços.
**Mobile:** Use "Adicionar à tela inicial" (Android) ou "Adicionar à Tela de Início" (iOS).

### O aplicativo funciona offline?
Sim, com limitações. Você pode visualizar dados já sincronizados e adicionar novas transações. A sincronização ocorre automaticamente quando a conexão é restabelecida.

### Como funciona a sincronização entre dispositivos?
Os dados são sincronizados automaticamente. Se houver conflitos (mesma transação editada em dispositivos diferentes), o sistema priorizará a modificação mais recente.

### Posso usar em múltiplos navegadores?
Sim. Faça login com suas credenciais em qualquer navegador moderno. Seus dados estarão sempre sincronizados.

## Relatórios e Análises

### Como interpretar os gráficos do dashboard?
- **Gráfico de pizza:** Mostra distribuição percentual dos gastos por categoria
- **Gráfico de linha:** Apresenta evolução temporal de receitas e despesas

## Problemas Técnicos

### A aplicação está lenta. O que fazer?
1. Verifique sua conexão com a internet
2. Feche outras abas do navegador
3. Limpe o cache da aplicação
4. Reinicie o navegador
5. Se persistir, entre em contato conosco

### O PWA não sincroniza quando volto online
1. Abra a aplicação
2. Puxe a tela para baixo (refresh)
3. Aguarde alguns minutos para sincronização automática

### Como reportar um bug ou problema?
1. Acesse nosso [GitHub Issues](https://github.com/Finboostplus/finboostplus-app/issues)
2. Clique em "New Issue"
3. Descreva detalhadamente o problema
4. Inclua capturas de tela se possível
5. Informe navegador e sistema operacional

## Planos e Limites

### O FinBoost+ é gratuito?
Sim, o FinBoost+ é completamente gratuito durante o período de projeto acadêmico.

### Existe limite de transações ou grupos?
Não há limites definidos para registro de transações. E são permitidos até 6 grupos para cada usuário.

### Posso usar para fins comerciais?
O FinBoost+ foi desenvolvido para uso pessoal e de pequenos grupos. Para uso comercial extensivo, entre em contato conosco.
