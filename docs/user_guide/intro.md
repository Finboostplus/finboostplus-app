# Guia do Usuário - FinBoost+

Bem-vindo ao **FinBoost+**, sua solução para controle financeiro em grupos. Este guia irá orientá-lo através de todas as funcionalidades da aplicação.

## O que é o FinBoost+

O **FinBoost+** é uma aplicação web moderna que permite gerenciar suas finanças e dividir despesas com outras pessoas de forma automática e intuitiva. Seja para controlar gastos, dividir contas com amigos ou gerenciar as finanças de uma viagem em grupo, o FinBoost+ oferece as ferramentas necessárias.

## Principais Recursos

### Controle Financeiro 
- **Registro de receitas e despesas** com categorização automática
- **Acompanhamento de saldos** em tempo real
- **Relatórios visuais** com gráficos interativos

### Gestão Compartilhada
- **Criação de grupos** para divisão de gastos
- **Divisão automática** de despesas entre membros
- **Controle de saldos** individuais no grupo
- **Notificações** de pendências e atualizações

### Interface e Experiência
- **Design responsivo** que funciona em qualquer dispositivo
- **Tema claro e escuro** conforme sua preferência
- **Aplicação PWA** instalável em desktop e mobile
- **Sincronização em tempo real** entre dispositivos

## Requisitos do Sistema

### Para Uso Web
- **Navegador moderno:** Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Conexão com internet** para sincronização
- **JavaScript habilitado**

### Como Aplicativo (PWA)
- **Sistemas suportados:** Windows 10+, macOS 11+, Android 8+, iOS 14+
- **Funcionalidades offline** limitadas disponíveis

## Segurança e Privacidade

O FinBoost+ foi desenvolvido com foco em segurança:

- **Autenticação JWT** com tokens seguros
- **Não compartilhamento** de dados pessoais com terceiros
