# Instalação e Setup

Este guia mostra como começar a usar o FinBoost+ em diferentes plataformas e dispositivos.

## Acesso via Navegador Web

### Requisitos Mínimos
- **Navegador:** Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **JavaScript:** Habilitado
- **Conexão:** Internet estável

### Como Acessar
1. Abra seu navegador preferido
2. Acesse: `https://finboost.app` (URL será atualizada quando disponível)
3. A aplicação carregará automaticamente

## Instalação como Aplicativo (PWA)

O FinBoost+ pode ser instalado como um aplicativo nativo em seu dispositivo, oferecendo uma experiência mais integrada.

### Desktop (Windows/Mac/Linux)

**Google Chrome:**
1. Acesse o FinBoost+ no navegador
2. Clique no ícone de instalação na barra de endereços
3. Selecione "Instalar FinBoost+"
4. O aplicativo será adicionado ao menu inicial/dock

**Microsoft Edge:**
1. Acesse o FinBoost+ no navegador
2. Clique no menu (três pontos) > "Aplicativos"
3. Selecione "Instalar este site como aplicativo"
4. Confirme a instalação

### Mobile (Android/iOS)

**Android (Chrome):**
1. Acesse o FinBoost+ no Chrome
2. Toque no menu (três pontos)
3. Selecione "Adicionar à tela inicial"
4. Confirme o nome e toque em "Adicionar"

**iOS (Safari):**
1. Acesse o FinBoost+ no Safari
2. Toque no ícone de compartilhamento
3. Selecione "Adicionar à Tela de Início"
4. Confirme o nome e toque em "Adicionar"

## Criando sua Conta

### Registro de Nova Conta

1. **Acesse a tela de registro**
   - Na página inicial, clique em "Crie sua conta"

2. **Preencha os dados básicos**
   - Nome completo
   - Email válido
   - Senha segura (mínimo 8 caracteres)
   - Confirmação da senha

3. **Aceite os termos**
   - Aceite os Termos de Uso e Política de Privacidade

### Recomendações para Senha

Para garantir a segurança de sua conta, sua senha deve conter:

- Mínimo de 8 caracteres
- Pelo menos uma letra maiúscula
- Pelo menos um número
- Pelo menos um caractere especial (!@#$%^&*)

## Acesso a Conta

### Login

1. **Digite suas credenciais:**
   - Email cadastrado
   - Senha criada
2. **Clique em "Entrar"**

## Resolução de Problemas Comuns

### Erro ao Fazer Login
- Verifique se email e senha estão corretos
- Certifique-se de que sua conta foi confirmada
- Use "Esqueci minha senha" se necessário

### PWA Não Instala
- Verifique se está usando HTTPS
- Limpe o cache do navegador
- Tente em modo privado/incógnito primeiro

### Problemas de Performance
- Feche outras abas do navegador
- Limpe o cache da aplicação
- Verifique sua conexão com a internet
